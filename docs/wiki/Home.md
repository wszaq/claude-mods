# claude-mods Wiki

Five Claude Code mods support local session checks, command counts, repository verification, peer boards, and file delivery.

Start with [Installation](Installation), then follow [Usage](Usage).
Use [Mod Reference](Mod-Reference) for commands and configuration.
Read [Architecture](Architecture) for local data and dependencies.
Use [Troubleshooting](Troubleshooting) if a feature does not work.

The repository stores the wiki navigation source in [docs/wiki](https://github.com/wszaq/claude-mods/tree/main/docs/wiki).
