# Ops journal — 2026-10-24

## session-panel 0.3.0: Outputs lists the files made for you

The operator reported that the Outputs card showed other files, not the files that agents make for them.
Version 0.2.3 listed every successful Write, Edit, and NotebookEdit path.
A replay of 12 real sessions found 119 entries. Most were edits, memory notes, activity logs, and scratch files.

The operator chose the rule "made for you" from three options. The card now adds a file in these cases:
- A SendUserFile call sends the file, or an Artifact call publishes it.
- A Write call creates the file. The Write tool result has `type: "create"`.
- A shell command names a document file and changes it while the command runs.
  The extensions are the deliverable-dock defaults: `.pdf .pptx .docx .xlsx .html .png .jpg .mp4 .mov .zip`.

Edits only move a listed file to the top. Scratch and temp files stay out.
Hidden files and folders stay out, and so do paths with the session ID. Sent files are always added.
Files from subagents count. The same replay with this rule found 27 entries.

## Lesson

`$.fs.stat` resolves a relative path or a `~/` path against the plugin folder, not the session folder.
Make each path absolute before the call.
