# Ops journal — 2026-10-24

## session-panel 0.3.1: price per subagent

The operator asked for a price on each row of the Subagents card, next to tokens and time.
A new `turn.step` hook prices each model call of a subagent and adds it to a sum for that agent id.
The row shows the sum after tokens and time. A model that is not in the price table shows no price.
The SafetyHeads team copy got the same change as `session-panel` 0.2.1, with Polish number format.

## Findings

The Agent tool result gives `totalTokens` and `usage` of the last model call only.
In 8 of 8 checked runs, this number was 4 to 20 times smaller than the sum in the subagent transcript.
Thus the mod cannot get the price from the Agent result.

A foreground subagent sends its `turn.step` events before its Agent tool call returns.
Thus the mod keeps the sum by agent id and joins it to the row when the pane draws.

In 4,707 subagent model calls from 14 days, no call wrote the 1-hour cache.
Thus a cache write counts at the 5-minute rate (1.25 times the input price).
Claude Haiku 5.5 costs 5 times more for a prompt over 100K tokens. 33 of 178 Haiku 5.5 calls were over 100K.
The hook prices each call, so it applies the higher rate only to these calls.
